# Hanoi

Al realizar este programa comprendí mejor cómo funciona la recursividad y cómo aumenta la cantidad de movimientos al incrementar los discos. Con los resultados observé que para 5 discos se necesitan 31 movimientos, mientras que para 64 se requieren más de 18 trillones. Esto me ayudó a entender que, aunque el código pueda calcular la solución rápidamente, ejecutar todos los movimientos puede ser muy tardado. Todavía estoy aprendiendo a medir y optimizar programas, pero esta actividad me permitió comprender la importancia de analizar su rendimiento.
